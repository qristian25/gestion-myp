Instrucciones para Publicar en GitHub & GitHub Pages

Listo para Exportar
1

Crear el Repositorio en GitHub

Ingresa a github.com/new y crea un repositorio público llamado simulador-impresiones-myp.

2

Subir los Archivos con Git (o Script Automático)

Puedes ejecutar el archivo deploy_to_github.bat incluido en esta carpeta, o usar los siguientes comandos en tu terminal:

cd "c:\Users\FRANCO\Downloads\ING SOFTWARE DOCS\proyecto\simulador-impresiones-myp"
git init
git add .
git commit -m "feat: Simulador interactivo de conteo y control de impresiones M&P"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/simulador-impresiones-myp.git
git push -u origin main
3

Activar GitHub Pages (Web en Vivo Gratis)

En tu repositorio en GitHub: ve a Settings → Pages → Branch: main / root → Save. En menos de 1 minuto tendrás tu enlace público oficial para compartir en la presentación:

URL Pública: https://TU_USUARIO.github.io/simulador-impresiones-myp/
